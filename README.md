# DKHH · 신의전당 보조바퀴

게임 화면을 읽어 성유물 선택을 돕는 Windows용 프로그램입니다.

## 다운로드 및 사용법

1. [최신 릴리즈](https://github.com/ckslcksl/DKonlineHH/releases/latest)에서 파일을 받습니다.
   - `DKHH.exe`: 단일 실행 파일.
2. Windows 10/11 64비트에서 한국어 OCR이 설치된 상태로 사용합니다.
3. 프로그램에서 게임 창을 연결하고 **고유·추가 옵션 선택**으로 원하는 조건을 고릅니다.
   - 고유 옵션 미선택: 고유 조건 제한 없음.
   - 각 목록 안은 OR, 고유와 추가 조건 사이는 AND입니다.
   - 강조 기준: 추가 옵션이 가능한 종류 / 현재 카드에 실제 옵션이 붙은 경우.
4. 게임의 성유물 선택 화면으로 돌아가면 자동으로 읽고 강조합니다. 고유 적중은 노랑, 추가 적중은 파랑입니다.
5. 카드 하단의 고정 통계: **잠금 N / 남은 유효 M / 전체 O**. 남은 유효는 조건에 맞는 종류에서 잠금·임시 보유를 제외한 수입니다.
6. 카드 선택·확정·화면 전환을 확인하면 임시 보유로 저장합니다. 선택 당시 등급도 함께 저장합니다. 임시 보유 행을 우클릭하면 **잠금 보유로 이동 / 삭제**할 수 있고, 전체 이동 버튼도 있습니다. 카드의 1·2·3번 위치는 목록에 표시하지 않습니다.
7. **임시 보유 초기화**는 임시 목록만 지웁니다. 잠금 보유는 유지됩니다. 인식 오류는 수동 추가·해제로 보정하세요.

창을 가리거나 게임 UI 배율을 바꾸면 인식이 달라질 수 있습니다. 화면 캡처·OCR 및 클릭 관찰을 사용하며 게임 메모리나 패킷을 읽지 않습니다.

## Windows 실행 차단

- **SmartScreen의 인식되지 않은 앱 경고**와 **Defender의 특정 악성코드 탐지**는 다른 문제입니다. 이 릴리즈는 코드 서명 인증서가 적용되지 않았습니다.
- 공식 릴리즈의 `SHA256SUMS.txt`로 다운로드 파일 무결성을 확인하세요. 해시 일치는 악성코드 검증을 대신하지 않습니다.
- 실제 위협 이름이 표시되면 탐지명과 파일 SHA-256을 Issues에 알려 주세요. 검토 후 필요시 [Microsoft 오탐 검토](https://www.microsoft.com/en-us/wdsi/filesubmission)에 개발자 자격으로 제출합니다. 탐지만으로 오탐이라고 단정하지 않습니다.
- 백신을 끄거나 광범위한 제외 폴더를 추가하는 방식은 권하지 않습니다. 장기 대응은 검증된 코드 서명과 동일 게시자 인증서의 지속 사용입니다. 서명만으로 새 파일의 경고가 즉시 사라지지는 않습니다.

참고: [Microsoft SmartScreen 안내](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation), [개발자 탐지 이의 제기 안내](https://learn.microsoft.com/en-us/defender-xdr/developer-faq).
